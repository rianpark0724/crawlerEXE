# 그림 요청서

게임 속 웹페이지에 들어갈 그림 목록이다. 그림 생성 AI(GPT 등)에 한 항목씩 넣어 만들고, 결과를 **파일 이름 그대로** `assets/images/` 아래에 넣으면 게임에 바로 나온다. 파일이 없으면 게임은 회색 자리에 파일 이름을 표시한다.

## 쓰는 법
1. 아래 **사이트 공통 스타일**과 항목의 **내용**을 함께 그림 AI에 넣는다.
2. **크기**대로 만든다. 비율이 다르면 잘라서 맞춘다.
3. `assets/images/<파일 이름>`에 PNG로 저장하고, 그 항목의 **상태**를 `완료`로 바꾼다.

## 항목 양식
```
### <파일 이름>                       예: news/sighting_lead.png
- 쓰는 곳: <사이트> / <문서 제목> / <대표 사진·본문 사진·관련 기사 썸네일 등>
- 크기: <가로> × <세로> px (<비율>), PNG
- 내용: <그림에 들어갈 장면 설명 — 그대로 프롬프트로 쓸 수 있게>
- 피할 것: <글자·실제 로고·실존 인물 등>
- 상태: 요청 | 완료
```

## 공통 규칙 (모든 사이트)
- **글자를 넣지 않는다.** 게임이 글을 따로 그린다. 간판·화면 속 글도 흐리게 뭉개서.
- **실제 로고·브랜드·실존 인물을 넣지 않는다.** 가상의 세계다.
- 게임 화면이 어두운 테마라 **너무 밝은 흰 배경은 피한다.**
- 주인공 "크롤러"의 모습: 짙은 남색 반투명 **정사각형 마디** 3–6개가 일렬로 이어지고, 마디마다 **가늘고 긴 흰 다리 한 쌍**(무릎이 위로 솟은 지네 다리). 머리 마디 앞쪽에 **작은 주황 점**(눈). 크기는 글자 몇 개 정도로 작다.

## 뉴스 사이트 (스테이지 2) — W·E·B 뉴스

### 사이트 공통 스타일
보도 사진처럼 사실적인 사진 톤. 어둡고 대비가 강한 색, 약한 필름 입자. 배경은 **웹페이지 화면 속 세상** — 흐릿한 글줄, 파란 링크 글자, 버튼과 상자들이 바닥과 벽처럼 보이는 미니어처 세계를 아주 가까이서 찍은 접사 사진 느낌. 시간대는 밤, 화면 빛이 주변을 비춘다.

### 참고: 관련 기사 썸네일
관련 기사 카드의 썸네일은 **그 기사의 대표 사진을 줄여서** 쓴다(따로 만들 필요 없음). 그래서 위의 `related_links.png`, `related_revert.png`, `related_shop.png`는 각각 기사 "링크만 골라 먹는다…", "백과사전, '되돌리기 봇' 늘려…", "쇼핑몰도 안전하지 않다…"의 대표 사진으로도 쓰인다.

### 일상 기사 스타일 (아래 8장)
위의 "웹페이지 속 미니어처 세계"가 아니라 **평범한 현실의 보도 사진**이다. 실제 신문 기사 사진처럼 자연스러운 구도와 조명, 다만 게임 화면에 맞게 **저녁·밤의 어둑한 톤**과 약한 필름 입자. 사람은 뒷모습·먼 거리·흐릿하게(얼굴을 알아볼 수 없게). 크롤러는 나오지 않는다.
