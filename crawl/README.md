# CRAWL.EXE

다리로 밟아서 긁어모으는 웹 크롤러 액션 게임 — 2D 게임 프로그래밍 텀 프로젝트

- 게임공학과 · 2023184013 · 박준서
- Python 3 · pico2d

## 실행
```
pip install pico2d
python main.py
```

## 조작
- 마우스 이동: 이동 · 좌클릭: 질주/돌진 · 우클릭: 무적 액션 · ESC: 일시정지
- F1: 디버그 뷰 · F12(타이틀): 전체 임시 해금
